## C) Level & Strategy

**The tech match is excellent** — Java/Spring Boot (primary) + Angular (3yr enterprise) + Oracle (preferred DB) maps almost perfectly to the JD. This combination is rare: most candidates have either Java OR Angular at this depth, not both in production.

**The blocker is comp, not fit.** Fidelity India has historically paid conservatively — Glassdoor shows ₹20L median for this title. That is below Stevens' ₹30L minimum.

**If pursuing:**
1. Call the recruiter before applying to confirm comp range — don't invest tailoring time without ₹35L+ confirmed
2. Lead with Java/Spring Boot + Angular 3yr combination as a rare differentiator
3. Oracle SQL is a specific match — call it out as the preferred DB in the JD
4. AI/ML desirable: "I have two production AI systems shipped — I can accelerate any ML integration roadmap"
5. Frame Insurtech ↔ Asset Management: regulated financial data, IRDAI compliance, audit trails = same mindset

**Do not tailor the CV until comp is verified.**
