## C) Level & Strategy

**Score 3.7/5 — below the 4.0 strong-apply threshold.** The role is genuinely interesting and the archetype fit is real (TypeScript + AI agents). The main gap is that Stevens builds product features for end users, while this role is about developer-facing tooling — a distinct UX context.

**If applying:**
1. Lead with AI/agentic production systems: Admissibility AI Agent + Acko Global Care
2. Frame "eval-first approach" using Segment + Growthbook as analogues: "I instrument every feature before rollout — same mindset as AI evals"
3. Learn Supabase basics + pgvector fundamentals before applying (< 2 days)
4. Study MCP spec — this is new for most candidates, so baseline knowledge puts you even with others
5. Position the dashboard assistant angle: Stevens built SDUI dashboard components (Claim Timeline, RSA tracking UI) — this maps to the AI dashboard assistant work

**Fit verdict:** Apply if you're excited about developer tooling and infrastructure. If you want to stay in product-facing AI (B2C, insurance, consumer apps), wait for a better-matched role.
