   - S: Built React frontend for enterprise procurement cost management system alongside Spring Boot microservices
   - T: System manual approvals bottleneck (40% efficiency), scale concerns, no governance audit trail

3. **Distributed Coordination — API Contracts & Cross-team Ownership**
   - S: Acko RSA/PUD platforms with 3+ teams (backend, mobile, analytics) sharing APIs
   - T: API contract inconsistencies, frontend blocked waiting on backend, duplicated logic

   - R: Teams shipped independently, zero integration surprises, clear contracts reduced coordination overhead
