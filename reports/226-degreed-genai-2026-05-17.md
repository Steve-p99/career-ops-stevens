## F) Interview Preparation

**Master Stories:**

1. **Admissibility AI Agent — Human-in-Loop Claims Classification**
   - S: Built UI for AI claims classification (admissible, fraudulent, manual review needed)
   - T: Raw AI output confuses claims handlers; no way to understand why decision made; handlers ignore recommendations
   - A: Designed verdict display + per-rule pass/fail breakdown + supporting evidence section. Implemented override signals (when handler disagrees) feeding back to model retraining pipeline
   - R: Handlers trust system (evidence increases confidence), override signals improve model, claims processing faster
   - **Reflection:** *AI UX is teaching humans to work with AI* — show evidence, enable overrides, make decisions explainable

2. **Acko Global Care — LLM Medical Tourism Platform**
   - S: Built UI for LLM-powered medical tourism platform (diagnosis extraction → hospital recommendation → treatment cost → best doctor ranking)
   - T: End-to-end LLM pipeline complex; users don't understand recommendations; UX for chained AI calls unclear
   - A: Designed step-by-step UI showing each LLM stage (extracted diagnosis → matching hospitals → cost estimation → ranking logic), real-time token streaming, confidence scores
   - R: 4th place Ackathon, clear flow helped users make decisions, LLM outputs understandable
   - **Reflection:** *Complex AI chains need UI scaffolding* — show reasoning, enable exploration, build trust

3. **Feature Flags for AI Rollout — Growthbook Integration**
   - S: Building AI features in fast-moving company means A/B testing + gradual rollout
   - T: AI model changes risky (can harm user experience); need safe rollout + monitoring
   - A: Integrated Growthbook feature flags with Acko AI features (Admissibility, Claims timeline). Built monitoring UI (Datadog) to track AI performance by flag variation
   - R: Safe AI rollouts, fast iteration, data-driven decisions on model changes
   - **Reflection:** *AI features need infrastructure for safety* — flags, monitoring, gradual rollout
